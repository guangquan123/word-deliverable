# Word 正式交付文档验收清单

本文件是 `word-deliverable` skill 的交付前强制验收清单。`validate_docx.py` 负责 DOCX/XML 结构校验，`validate_pdf.py` 负责默认无图片文本坐标验收。**任何问题项不通过，视为生成尚未完成，必须修复后重新生成/更新/检查。**

验收模式：

- `pdf-text`（默认）：DOCX/XML 通过后导出一份新 PDF，检查文本层、文本坐标、页面边界、非设计性空白页、页尾孤立标题、内部稀疏页和末页残余。
- `none`：只做 DOCX/XML 检查；适用于用户明确不需要 PDF 验收的场景。
- `raster`：仅在用户明确要求逐页看图，或 `pdf-text` 发现无法判断的高风险异常且用户同意后，对 `.deepworks/tmp/` 中少量疑似页面做人工复检；不得默认全量栅格化。

## A. 文档结构检查

- [ ] 封面完整且独立成页
- [ ] 目录独立成页
- [ ] 文档控制位置正确（目录之后、正文之前）
- [ ] 正文从正确位置开始
- [ ] 附录位置合理
- [ ] 前置模块顺序：封面 → 目录 → 文档控制 → 前言(如有) → 正文 → 附录

## B. 标题检查

- [ ] Heading 1–6 均绑定正确 `numId`、`ilvl`，且 `numbering.xml` 中存在对应定义
- [ ] 小节标题使用独立 Style（非正文+手工加粗）
- [ ] 编号连续无跳号
- [ ] 一级标题显示"第一章"而非"第1章"（中文计数）
- [ ] 无手工模拟标题（Normal + 加粗 + 字号）
- [ ] 标题层级控制在 3～4 层以内

## C. 目录检查

- [ ] 目录已生成（TOC 字段已展开为真实内容）
- [ ] 有真实章节名称
- [ ] 有真实页码且正确
- [ ] 层级正确
- [ ] 点线引导符正确
- [ ] 页码右对齐
- [ ] 不存在"请按 F9 更新目录/请右键更新域/目录待生成"等提示

## D. 字段检查

- [ ] PAGE 字段正常显示当前页码
- [ ] NUMPAGES 字段正常显示总页数
- [ ] TOC 字段已刷新到最终状态
- [ ] Caption（表题/图题）编号连续正常
- [ ] Cross-reference（如有）正常

## E. 表格检查（逐表）

- [ ] 未超出正文页面区域
- [ ] 无文字溢出
- [ ] 表格使用固定布局且网格列宽均为正数
- [ ] 第一行已设置重复标题行
- [ ] 每一行均设置禁止跨页拆分
- [ ] 无孤立尾行
- [ ] 列宽合理（长文本不拥挤，无严重失衡）
- [ ] 字号统一
- [ ] 黑色细边框，表头浅灰底加粗
- [ ] 短字段居中，长文本左对齐，单元格垂直居中

## F. 分页检查

- [ ] 非设计性空白页 = 0
- [ ] 无孤立标题（标题在页尾、正文在下页）
- [ ] 无孤立正文（下页只有一两行）
- [ ] 无孤立表格尾行
- [ ] 最后一页无仅少量残余内容
- [ ] 无图片与图题分离
- [ ] 无表格与表题分离
- [ ] 无连续回车/空行顶页

## G. 页眉页脚检查

- [ ] 封面正确隐藏页眉页脚
- [ ] 正文页眉一致（项目名称 + 文档名称）
- [ ] 页码连续无跳号
- [ ] 总页数正确
- [ ] Section 未导致格式断裂
- [ ] 页脚居中"第 X 页 共 Y 页"

## H. PDF 文本坐标验收（默认 `pdf-text`）

- [ ] 本次导出确实产生了新的非空 PDF，不接受旧文件误判成功
- [ ] PDF 可打开、页数大于 0、有可检索文本层
- [ ] 无文本触及或越过页面安全边界
- [ ] 无非设计性空白页
- [ ] 无大面积异常空白或内部异常稀疏页
- [ ] 无页尾孤立标题
- [ ] 末页无仅少量残余内容
- [ ] 表格无异常分页或孤立尾行
- [ ] 如文本坐标无法判断高风险异常，仅在用户同意后栅格化少量疑似页面

## I. 样式与工程检查

- [ ] 正文使用当前 `layout_profile` 对应的“正文”Style；默认 `government` 为仿宋 14pt、首行缩进 2 字、固定行距 28pt
- [ ] 标题用 Heading Style 而非直接格式
- [ ] 列表用 Word 原生编号/项目符号
- [ ] 无手工空格/Tab 模拟版式
- [ ] 无过程文字（TODO/待生成/示例占位符/AI 说明/请用户自行调整）

## 零缺陷交付门槛

以下任一情况存在，视为 Word 生成尚未完成：

- 需要用户更新目录
- 需要用户修改页码
- 需要用户删除空白页
- 需要用户调整表格
- 需要用户修正编号
- 需要用户统一字体
- 需要用户调整标题
- 存在孤页或孤行
- 存在明显格式漂移
- 存在制作过程提示
- 存在明显的 AI 默认排版痕迹

发现问题后流程：修改 → 重新生成/更新 → 再次检查 → 确认无明显问题 → 才能交付。

## 最终判断标准

不要问"Word 大体上是不是已经做好了？"，必须问：

> **如果现在把这个文件直接发给客户或领导，我是否还需要手工修任何格式？**

如果答案是"需要"，说明文档尚未达到交付标准。
